**TURBOCURSA 1.5.0**: clean-room pseudo-3D arcade racer in Rust, native (minifb) and web (WASM), 8 languages, MIT.

- **Play in the browser:** download `turbocursa.html` and open it (a single self-contained file, no server needed).
- **Native:** `cargo run --release --features native --bin turbo` (add `--features audio` for sound).
- **Source:** `turbocursa-1.5.0-src.zip`. Checksums in `SHA256SUMS`.

Highlights: endless mode, coins and garage, shareable stage/championship/ghost codes, daily and weekly stages, settings that persist, a hardened web page. See `CHANGELOG.md`.

Not verified on real hardware: sound output, touch devices, Safari/Firefox, Windows/macOS builds.
